# OP28 Academia

Site institucional da OP28 Academia, em Santos/SP, com layout responsivo, animações, filtros de modalidades, perguntas frequentes, mapa e contatos por WhatsApp e Instagram.

## Estrutura

- `index.html`: página principal.
- `styles.css`: estilos, animações e adaptação para celular.
- `script.js`: menu, filtros, efeitos de entrada e mensagens de WhatsApp.
- `assets/`: fotos e logo restauradas em maior resolução, além dos favicons.

## Visualizar e publicar

Abra `index.html` em um navegador ou publique a raiz deste repositório em uma hospedagem estática. Não há dependências nem etapa de build.

Para GitHub Pages, use a branch `main` e a pasta `/ (root)` nas configurações do repositório.

As fontes do Google, o mapa e os links externos precisam de conexão com a internet. As imagens ficam no próprio repositório.
